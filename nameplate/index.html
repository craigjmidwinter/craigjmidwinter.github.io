STL has no colours or parts, so the zip holds one STL per colour of each plate (base, letters, stick). For several colours, load a plate's files together as one object. The 3MF does this for you.

LOADING THE TOOL…

No plates yet. Type at least one name.

ONE PIECE

Every plate prints as a single piece. Where letters stand apart, or a name has a space, the tool adds a joining bar along the bottom of the letters.

PRINTING

Open the 3MF in Bambu Studio or PrusaSlicer. Each plate comes in as one object with its base, letters and stick ready to colour. The STL zip has the same parts as separate files, with a README on how to load them.
